## 项目目标

面向设备数据接入与通信调试，将任意切块的字节流还原为经过校验的数据帧，定位损坏数据并在后续分隔符处恢复接收。交付可复用的 MoonBit 核心库与离线回放 CLI，让半包、粘包和坏帧问题能用一份日志复现。

## 功能与技术路线

采用参考帧格式 COBS(payload + CRC16) 加零分隔符。核心实现 COBS 编解码、CRC-16/IBM-3740 校验、有界增量状态机、绝对字节区间与 JSON 报告；区分格式错误、缺少校验码、CRC 不匹配、超限和截断五类问题。默认待解析逻辑缓存上限为 4096 字节，超限后丢弃至下一分隔符。

## 工程特色

将切块一致性、资源边界、故障恢复与回放证据放在同一组件中。核心库独立于设备 I/O，可在 JavaScript 与 WebAssembly GC 复用；CLI 仅用少量 JS 适配代码读取文件和设置退出码。COBS 和 CRC 为已有算法，项目不声称算法首创。

## 首版成果与验证

已实现本地 v0.1.0，JS 与 wasm-gc 各通过 25 项测试，包含 1024 组确定性编解码生成样例、100 组任意字节流检查和 56 次单比特载荷变异。独立 Python 参考检查验证 15 组双向帧向量及 CLI 行为。合成传感器演示可恢复两条正常消息，并定位中间 [13,18) 区间的 CRC 错误。

## 交付范围与后续计划

首版包含源码、Apache-2.0 许可证、README、测试、合成示例、预编译 CLI 与 CI 配置。下一步补齐公开仓库、远程 CI 和本人复现记录，按审核反馈迭代。尚未完成真实设备联调；不包含串口或蓝牙驱动、GUI、重传和任意协议自动识别。
